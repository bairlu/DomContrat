# DomContrat — PDF et GitHub Pages

الموقع: https://bairlu.github.io/DomContrat/

المستودع: https://github.com/bairlu/DomContrat

منصة ثابتة بـHTML وCSS وJavaScript لإعداد عقود العمل المنزلي بالعربية والفرنسية عبر سبع مراحل. المعاينة والتحميل **PDF فقط**، بنص قابل للتحديد والنسخ. لا Backend ولا قاعدة بيانات ولا حسابات.

## الخصوصية

توجد البيانات في ذاكرة الصفحة فقط. لا LocalStorage أو SessionStorage أو IndexedDB أو Cookies أو تحليلات أو خدمات توليد خارجية. المكتبات والخطوط محلية، والتوليد داخل المتصفح. تحديث الصفحة أو إغلاقها يمسح البيانات، مع تحذير مغادرة عند وجود تعديلات. لا تضف بيانات عقود إلى URL أو سجلات أو مستودع Git.

## التشغيل والبناء

للمطور فقط: Node.js 24 وnpm.

```bash
npm ci
npm run licenses
npm run build
npm test
npm start
```

يفتح الموقع على http://localhost:5173/ . يمكن اختيار منفذ آخر بواسطة `node scripts/serve-local.mjs --port=5174`. المرتفق لا يحتاج Node.js؛ يستعمل الرابط المنشور أو ملفات dist الجاهزة. ملف index.html في جذر المصدر يحتاج البناء أولاً. لا تستضف جذر المصدر مباشرة، بل انشر محتويات dist.

## النشر والتحديث

المستودع الحالي ينشر main تلقائياً عبر `.github/workflows/pages.yml`. GitHub Pages مضبوط على **GitHub Actions**. كل دفعة تشغّل npm ci والتراخيص والبناء والاختبارات ثم تنشر **dist فقط**؛ لا يوجد خادم دائم.

بعد التعديل واختبارات الملف الفعلي، راجع الملفات المضافة وافحص الأسرار ثم:

```bash
git add <reviewed-files>
git commit -m "Describe the update"
git push origin main
```

انتظر نجاح build وdeploy في Actions ثم اختبر الرابط العام ومعاينة PDF وتحميله باللغتين. لا تدفع ملفات .env أو الرموز أو العقود المعبأة أو مخرجات الاختبار. راجع AGENTS.md لإجراءات الصيانة. جميع مسارات التطبيق نسبية وتعمل تحت /DomContrat/.

للنشر من حزمة ثابتة مستقلة: انشر محتويات dist في جذر فرع مستقل ثم اختر Settings → Pages → Deploy from a branch. لا تغيّر مصدر النشر الحالي إلى فرع المصدر دون بناء نسخة ثابتة منفصلة.

## ربط نطاق خاص

1. بعد امتلاك النطاق، أضفه في Settings → Pages → Custom domain.
2. للنطاق الفرعي، أضف سجل CNAME نحو bairlu.github.io. للنطاق الرئيسي اتبع سجلات DNS الحالية من توثيق GitHub أدناه.
3. أضف ملف public/CNAME بسطر النطاق وحده؛ يحافظ البناء عليه في dist.
4. تحقق من DNS وملكية النطاق ثم فعّل Enforce HTTPS بعد جاهزية الشهادة.

لا يوجد نطاق خاص مضبوط حالياً. لا تضف نطاقاً دون طلب صاحبه.

## مصدر النص والتحقق

- src/pdf.js: النص الكامل والبيانات الغليظة، المواد 1–7 والمادة 8 الاختيارية للمزايا، والتوقيعات وترقيم الصفحات الفعلي.
- src/legal.js: إلزامية البيانات، التواريخ والسن والساعات والأجر وحالات وثائق التعريف.
- src/legal-config.js: سجل الأجور المركزي بمراجع المراسيم وتواريخ السريان. لا يُكتشف التشريع تلقائياً من الإنترنت؛ يلزم تحديث إداري موثق عند تغيّره.
- src/app.js وsrc/i18n.js وsrc/style.css: المراحل واللغتان والتصميم والمعاينة.

البطاقة الوطنية تطلب تاريخ الصلاحية بدل الإصدار؛ جواز السفر وبطاقة الإقامة يطلبان الإصدار والانتهاء. تظهر البيانات المناسبة في العقد فقط. تُراعى صياغة جنس المشغل والعامل. الأجر شهري، ولا تخصم المزايا العينية منه.

حساب الحد الأدنى يستعمل decimal.js والتقريب إلى السنتيم الأعلى. جدول الشرح محذوف؛ رسالة الرفض تعرض الحد الأدنى المطلوب حسب الساعات دون تغيير الأجر المتفق عليه تلقائياً.

## PDF والطباعة

jsPDF وpdf-lib يولدان A4 داخل المتصفح بخط Amiri المضمّن المرخّص وفق OFL. لم يُعد توزيع خط Arial التجاري. المعاينة تستعمل Blob ملف PDF نفسه الذي يُحمّل، مع التكبير واختيار الصفحات. يوجد تنبيه Recto verso: العقد ذو الصفحتين يطبع على وجهي ورقة واحدة، وللعقود الأطول يُذكر عدد الأوراق المناسب دون تصغير الخط لإجبارها على صفحتين.

توضح ACCEPTANCE.md الاختبارات المنفذة وحدودها. اختبارات النص لا تعني تشغيل طابعة فعلية أو اعتماد العقد قانونياً من جهة مختصة.


## تسميات الملفات والمراجع

اسم PDF يتضمن اسم العامل الكامل: `عقد العمل المنزلي - (الاسم الشخصي والعائلي).pdf`. تُنظّف الرموز غير المسموح بها في أسماء ملفات Windows دون تغيير البيانات داخل العقد. تُحدد الصفة المهنية تلقائياً حسب جنس العامل، وتدرج المهام الحرة بعد عنوانها الصريح. يبقى تنبيه Recto verso أسفل معاينة الملف، خارج وثيقة العقد.

توجد في التذييل روابط الجريدة الرسمية من موقع الأمانة العامة للحكومة: العدد 6493 للقانون، والعدد 6609 للنموذج، والعدد 7469 للأجر. فُحصت الروابط الثلاثة وكانت تستجيب بملفات PDF حقيقية. لا تُحمّل هذه المصادر تلقائياً عند تحرير العقد؛ تفتح فقط عند اختيار الرابط، دون إرسال بيانات الاستمارة أو رابط إحالة.
